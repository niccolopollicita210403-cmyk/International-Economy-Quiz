Gestione dello studio

Le risposte corrette e non contrassegnate escono dal ciclo successivo. Le risposte errate e le domande ★ ritornano nel ripasso, anche se corrette. Le domande problematiche sono segnalate e non vengono considerate automaticamente acquisite.

Su iPad: apri il file HTML in Safari, se possibile. Il salvataggio automatico dei file locali può non essere stabile su tutte le versioni di iPadOS: usa periodicamente «Esporta progressi» e conserva il file JSON in File/iCloud Drive.

Informazioni e controllo delle fonti

Le risposte derivano dalle banche dati fornite. Alcune risposte sono state corrette quando emergevano contraddizioni evidenti; altre domande sono contrassegnate come ambigue o non valide e richiedono cautela. Non considerare la chiave originale infallibile.

Panoramica del ciclo

Tocca un numero per raggiungere la domanda. Verde = corretta; rosso = errata; ★ = contrassegnata.
